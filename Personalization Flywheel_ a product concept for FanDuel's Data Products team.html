Product concept · Data Product Manager, Personalization

One app. One customer.
Every screen personalized.

Most good personalization ideas never get tested. Experiment slots are scarce and readouts are slow. Here is the product I'd build to fix that: one ranking service behind every screen, and a flywheel that puts each test slot on the idea worth the most.

03
How I'd ship it

  
Small releases, each useful on its own.

  

   
Releases
    
    
  1. Idea queue that checks sample size and weeks to read. No model needed.
    2. 
    
  2. Offline pre-tests, starting with sportsbook home.
    3. 
    
  3. Ranking API v1 behind 2 screens.
    4. 
    
  4. AI-drafted hypotheses and readouts that analysts edit.

   
Metrics
    
    
  • North star: validated wins per quarter
    • 
    
  • Inputs: ideas pre-tested per week, days from idea to readout
    • 
    
  • Product: engagement and 7-day retention
    • 
    
  • Guardrails: responsible gaming triggers, opt-outs, latency

   
Trade-offs
    
    
  • Accuracy vs latency: precompute scores, rerank only the top 50 live
    • 
    
  • Cost: the LLM drafts test plans and readouts, never ranks live traffic
    • 
    
  • New customers: popular items for their state and moment until about 5 sessions
    • 
    
  • Decisions: a DACI for each screen owner
